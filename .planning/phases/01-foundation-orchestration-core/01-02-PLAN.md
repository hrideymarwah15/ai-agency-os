## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | audit_logs (post-hoc rewrite of AI decisions) | mitigate | Append-only service (record/query/list_recent — no UPDATE/DELETE methods, asserted by test) + PostgreSQL trigger `trg_audit_append_only` rejecting UPDATE/DELETE with 'audit_logs is append-only' (RESEARCH Pattern 3; defense-in-depth) |
| T-02-02 | Information Disclosure | /audit (audit data exposure) | mitigate | `Depends(get_current_owner)` on the route; no public read path; correlation_id/thread_id never rendered in UI (UI-SPEC Security-Adjacent) |
| T-02-03 | Spoofing | correlation_id query (guessing another trail) | mitigate | Owner-only route; correlation_id is a uuid4 secret-ish handle; no client-supplied IDs outside the single-owner session |
| T-02-04 | Tampering | payload rendering (stored XSS via audit payloads) | mitigate | Jinja2 autoescape ON; payloads rendered through escaped `<pre class="mono-payload">`; the UI never renders unescaped LLM or web content (UI-SPEC accessibility/security rules) |
