# Phase 02.1 Plan 01: Website Audits Summary

Automated website audits for every discovered lead: owner-triggered (one per lead), executed by an outbox worker, scored by deterministic rules, and surfaced through three server-rendered pages (audit list, per-lead history, per-audit detail).

## What Was Built

- **Audit schema (Task 01, `ccc42f2`)** — `WebsiteAudit` model + `AuditStatus` enum + JSONB result columns (scores, CWV, tech stack, CMS/hosting, analytics, broken links, gaps, security headers, raw stats), Alembic migration `0004_website_audit_schema`, `audit_version` + cap settings in `config.py`, Playwright pinned to `1.61.0`.
- **Detection & scoring (Task 02, `b4191e7`)** — deterministic signature table (CMS/hosting first-match-wins, stack/analytics set-union), static analyzer (title/meta/CWV signals, conversion-flow gaps), rule-based 0-100 scoring per dimension (performance, accessibility, SEO, mobile).
- **Rendered metrics (Task 03, `f1ee0dc`)** — Playwright renderer with browser-available probe (degrade to static), CWV observer (LCP/INP/CLS), mobile overflow probe; `fetch_stream` GET-based streaming probe added to the compliant HTTP client (etiquette-equivalent of HEAD).
- **Runner + worker (Task 04, `a4a9ba3`)** — `execute_audit()` orchestrating static → gated rendered → broken-link pass → ONE commit at completion; failures (robots denial, HTTP errors) mark the row FAILED with `last_error`. `audit_worker()` polls `audit.run` outbox events serially.
- **API + UI (Task 05, `1053b02`)** — four routes under `/website-audits` (index, lead history, detail, trigger), three new templates, `base.html` "Audits" nav link, `.score-grid` CSS delta, `audit_worker` wired into the app lifespan. Enqueue-only trigger in ONE transaction (RUNNING row + `audit.run` event + `audit_triggered` log), owner-guarded with Origin check (T-03-03).

### Auto-fixed Issues

**1. [Rule 1 - Bug] MockTransport handler wrapping in worker tests**
- **Found during:** Task 04 GREEN

- **Fix:** wrapped the handler; also replaced `Business.website` with `business.website_url` (schema column name) and switched to plain UUID capture before `expire_all()` to avoid a MissingGreenlet after commit.
- **Files modified:** `tests/test_audit_runner.py`, `tests/test_audit_worker.py`
- **Commit:** `a4a9ba3`

**2. [Rule 1 - Bug] CTA anchor with absolute external URL ignored by link pass**
- **Found during:** Task 04 GREEN
- **Issue:** the fixture CTA (`<a href="https://example.com">Get a quote</a>`) was skipped by the internal-link classifier; the "Get a quote" text assertion relied on it.
- **Fix:** fixture rewritten with relative CTA href so the internal sample includes it; absolute hrefs added explicitly as external links for the cap test.
- **Files modified:** `tests/test_audit_runner.py`
- **Commit:** `a4a9ba3`

**3. [Rule 1 - Bug] `_seed_audit` signature mismatch + orphaned fixture in API tests**
- **Found during:** Task 05 GREEN
- **Issue:** `clean_tables` fixture was a no-op (OutboxEvent/AuditLog rows leaked between tests → trigger test saw leftover events), and `_seed_audit` accepted `finished` while call sites passed `finished_at`.
- **Fix:** `clean_tables` now deletes OutboxEvent and TRUNCATEs `audit_logs` (DELETE is blocked by the append-only trigger — same approach as `test_approval_roundtrip.py`); parameter renamed to `finished_at`.
- **Files modified:** `tests/test_website_audits_api.py`
- **Commit:** `1053b02`

**4. [Rule 2 - Missing functionality] Route-registration order for detail vs lead paths**
- **Found during:** Task 05 GREEN
- **Issue:** `/website-audits/{audit_id}` could shadow `/website-audits/lead/{business_id}` depending on registration order.
- **Fix:** `lead/{business_id}` and `lead/{business_id}/run` registered before `/{audit_id}` (FastAPI first-match), verified by route ordering tests.
- **Files modified:** `backend/api/website_audits.py`
- **Commit:** `1053b02`

**5. [Rule 2 - Missing functionality] `website_url` not on WebsiteAudit — broken-link kind needed site domain**

- **Files modified:** `backend/api/website_audits.py`

**6. [Rule 1 - Bug] `type="checkpoint"` on `|lower` badge names for COMPLETED**

- **Files modified:** `backend/api/website_audits.py`, templates
- **Commit:** `1053b02`
