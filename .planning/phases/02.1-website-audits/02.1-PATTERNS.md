```python
async def audit_worker(*, poll_interval: float = _POLL_INTERVAL_SECONDS) -> None:
    """Drain audit.run outbox events serially until cancelled (D-12/D-40)."""
    while True:
        try:
            await _process_one()
        except asyncio.CancelledError:
            raise
        except Exception:  # noqa: BLE001 — a bad iteration must never kill the loop
            logger.exception("audit worker iteration failed")
        await asyncio.sleep(poll_interval)
```

### `backend/tools/http_client.py` (utility/fetch door — MODIFIED)

**Analog:** itself (exact). Add `fetch_stream()`; **do not touch `fetch()`** (lines 41-48). RESEARCH Code Ex 1 is the canonical body (lines 376-389):
```python
async def fetch_stream(self, url: str) -> tuple[httpx.Response, float]:
    """Robots-checked, throttled, header-only probe: returns (response, ttfb_ms)."""
    if not await self._policy.can_fetch(url):
        raise RobotsDeniedError(f"robots.txt denies fetching {url}")
    await self._bucket.acquire(urlparse(url).hostname or "")
    start = time.monotonic()
    async with self._client.stream("GET", url) as response:
        ttfb_ms = (time.monotonic() - start) * 1000
        return response, ttfb_ms
```
Uses the same robots → bucket → request pipeline (`http_client.py:43-45`) so link probes and TTFB never bypass the door (D-32). `import time` added at top.
