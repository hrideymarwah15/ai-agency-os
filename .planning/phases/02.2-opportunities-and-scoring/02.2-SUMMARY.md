## What shipped

### Schema (Migration 0005)
Added columns to `businesses`:
- `opportunities` (JSONB) — list of detected opportunity dicts
- `tier` (String(20)) — Hot/Warm/Cold/Raw classification
- `score_breakdown` (JSONB) — weighted factor breakdown for transparency
- `last_scored_at` (DateTime) — when scoring last ran
- Index on `tier` for filtering

### Opportunity Engine (`backend/services/opportunities/`)
- **`rules.py`** — `RuleEngine` loads YAML rules (`rules.yaml`) with hot-reload support. Detects opportunities via config-driven `gaps_contains` and `tech_stack_excludes` predicates.
- **`roi.py`** — `ROICalculator` computes `(time_saved × hourly_cost × frequency) - impl_cost` using industry×size hourly buckets and rule-template implementation costs.
- **`scorer.py`** — `LeadScorer` implements the 7-factor weighted rubric (Website Quality 20%, SEO Maturity 15%, Growth Signals 20%, Company Size 15%, Automation Potential 15%, AI Potential 10%, Budget Estimate 5%). Tier classification: Hot≥80, Warm≥60, Cold≥40, Raw<40.
- **`engine.py`** — `rescore_lead()` orchestrates: fetches business + latest completed audit → runs rule engine → calculates ROI per opportunity → scores lead → upserts JSONB fields on Business.
- **`worker.py`** — Outbox worker drains `audit.completed` events, resolves `business_id` via the audit row, and calls `rescore_lead`. Idempotent and cancellable.

### Audit Worker Update
Modified `backend/services/audits/worker.py` to emit an `audit.completed` outbox event after a successful audit run (payload: `audit_id`). This drives the opportunity rescoring pipeline.

### API & UI
- **`backend/api/discovery.py`** — Added `_to_lead_view_with_opps()` that augments the lead view with `tier`, `tier_badge`, `priority_score`, `top_opportunities` (top 3 by ROI), `last_audit_date`, and `pipeline_stage`.
- **`backend/templates/discovery.html`** — Extended leads table with new columns: Tier (badge), Score (emphasized), Top Opportunity (chip + ROI), Audit Status, Last Audit, Details (preserved), Actions (View Audit link). Added filter bar with tier multi-select, industry select, score range, and sort options.
- **`backend/static/app.css`** — Added styles for tier badges (`badge--tier-{hot,warm,cold,raw}`), score emphasis, opportunity chip, ROI value, and filter bar.

### Application Lifecycle
Updated `backend/main.py` lifespan to start the `opportunity_worker` alongside discovery and audit workers. Proper cancellation handled on shutdown.
