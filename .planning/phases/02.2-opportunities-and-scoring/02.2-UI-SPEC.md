## Pages

### `/discovery` — Extended Pipeline View (Phase 2 + 02.1 + 02.2)

**Purpose:** Single pipeline page showing qualified leads with audit status, tier badges, scores, top opportunities, and filtering/sorting.

**Inherits from Phase 2 discovery.html:**
- Page header + muted description
- Action row (if any CTAs)
- Zero-sources banner (when no leads)
- Runs table (recent discovery runs)
- Leads table (now EXTENDED with tier/opportunity columns)
- Empty states + limit notes
- Nav highlight (`active_page == 'discovery'`)

**Phase 02.2 Extensions (Leads Table — replaces Phase 2 §Page Anatomy "Leads section"):**

| Column | Content | Style |
|--------|---------|-------|
| Lead | Name (`.run-id` 13px mono), Industry, City | `.detail-list` (name=16px/600, industry=13px muted, city=13px mono) |
| Tier | Badge: Hot (red), Warm (amber), Cold (blue), Raw (slate) | `.badge--tier-{hot,warm,cold,raw}` — maps to existing token pairs |
| Score | 0-100 emphasized | `.score-value` (24px/600 tabular-nums blue-600) + `.score-label` "Score" |
| Top Opportunity | Name + ROI | `.opportunity-chip` (14px/400, max-width, ellipsis) + `.roi-value` (13px mono green-600) |
| Audit Status | Badge: Complete/Partial/Failed/None | Existing `.badge--status` mapping |
| Last Audit | Date | `.num` 13px |
| Actions | "View Audit" link (blue-600) | `.btn-ghost` inline |

**New Components:**

| Component | Spec |
|-----------|------|

| `.badge--tier-cold` | `background: var(--blue-100); color: var(--blue-700);` |

**CSS Delta (exact — only these additions to `app.css`):**

```css
/* Tier badges — map to existing token pairs */
.badge--tier-hot   { background: var(--red-100);   color: var(--red-700); }
.badge--tier-warm  { background: var(--amber-100); color: var(--amber-700); }
.badge--tier-cold  { background: var(--blue-100);  color: var(--blue-700); }

/* Opportunity chip + ROI */
.opportunity-chip { font-size: var(--text-sm); color: var(--text-primary); max-width: 200px; white-space: nowrap; overflow: hidden; text-overflow: ellipsis; display: inline-block; vertical-align: middle; }
.roi-value { font-size: 13px; font-family: var(--font-mono); color: var(--green-600); margin-left: var(--space-xs); }

/* Filter bar */
.filter-bar { display: flex; flex-wrap: wrap; gap: var(--space-sm); align-items: flex-end; margin-bottom: var(--space-md); padding: var(--space-md); background: var(--white); border: 1px solid var(--slate-200); border-radius: var(--radius-md); }
.filter-bar .input { min-width: 120px; }
.filter-bar .btn { height: 38px; }
```

**Accessibility + Responsive Notes (consistent with Phase 1/2):**
- All badges carry text labels (no icon-only)
- Filter form: `<label for="...">` + `visually-hidden` for compact layout; `aria-label` on multi-select
- Table: `th scope="col"`, first column `scope="row"`, `aria-label="Qualified leads pipeline"`
- Horizontal scroll wrapper `.table-scroll` for wide tables
- No hover-only affordances (desktop internal tool exception carries)
- Focus ring on all interactives (via existing `--blue-600`)
